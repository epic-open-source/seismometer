Replaced ydata-profiling with a built-in profiler for the feature reports (``feature_summary``, ``feature_alerts``, ``target_feature_summary`` and ``cohort_comparison_report``). The reports keep ydata-profiling's statistics, alert rules and ``alert_config.yml`` settings, work with pandas 3, and build about 3 times faster; ydata-profiling is no longer installed. Reports already in the output directory are still reused, so delete them to see the new reports. Raised the minimum versions to pandas 2.2, matplotlib 3.7 and great-tables 0.13; earlier versions failed when loading data, plotting or building tables.
