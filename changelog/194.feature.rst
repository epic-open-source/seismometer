Added support for pandas 3, pyarrow up to version 25 and great-tables 1.x, and for Python 3.14. Reduced the memory and time needed to load data by keeping string columns as Arrow-backed strings (the default ``str`` dtype on pandas 3) instead of ``object``, even where the data dictionary says ``object``, and by merging events on integer keys. Code that edits the loaded dataframe sees the new dtype: assigning a non-string value into one of these columns raises ``TypeError``.
